# Preview samples

One sample per format the file viewers of Sentinel show (ADR-0018), and hostile samples that must be refused or shown safely. The folder is mounted read-only into the SFTP server of the test stacks as `/preview-samples`, so every viewer can be tried in the development stack and is opened by the end-to-end test `preview.spec.ts`.

| Folder | What | Viewer |
|---|---|---|
| `binary/` | random bytes, an empty file, binary bytes named `.txt` | hexadecimal (D2.0) |
| `text/` | plain UTF-8 text, Go and Python code, an 800-line log | text with highlighting (D2.1) |
| `markdown/` | a rich README, and hostile Markdown (scripts, handlers, `javascript:` links, frames, forms, remote images) that must neither run nor load | Markdown in the isolated page (D2.1) |
| `data/` | JSON, JSON Lines, YAML with anchors, a YAML alias bomb, XML, broken JSON, CSV with 2000 rows, TSV, CSV with semicolons | tree and table (D2.1) |
| `images/` | PNG with transparency, JPEG with EXIF, animated GIF, WebP, AVIF, BMP, ICO, TIFF, an SVG, a hostile SVG (script, handlers, remote image, `javascript:` link) and a truncated PNG; regenerated by `generate-images.sh` | image, with zoom, rotation and metadata (D2.2) |
| `audio/` | a tone as WAV, MP3, Ogg Vorbis, Opus, FLAC and M4A (AAC); regenerated by `generate-media.sh` | audio player (D2.3) |
| `video/` | a clip as MP4 (H.264 and AAC) and WebM (VP9 and Opus), and an AVI (MPEG-4 Part 2) browsers do not play | video player (D2.3) |
| `pdf/` | a 30-page manual with text, a 3.7 MB document of 400 pages laid out for ranged reads, a PDF that asks to run JavaScript, one protected with the password `sentinel`, and a truncated one; regenerated by `generate-pdfs.py` | PDF with pdf.js in the isolated page (D2.4) |
| `archives/` | a small project (with a ZIP nested inside) as ZIP, 7z, RAR, TAR and TAR with gzip, bzip2, xz and zstd, a log compressed alone with each, a ZIP bomb, hostile entry names, 12 000 entries, a truncated ZIP, and a ZIP and 7z protected with the password `sentinel` (one with encrypted headers); regenerated by `generate-archives.py` | archive tree, read by the server (D2.5) |

Each stage of D2 adds its samples here. They are generated for Sentinel, so no third-party license applies.
