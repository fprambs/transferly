# Transferly 1.0.0-rc.1 — prerelease notes

This draft describes the stable-readiness changes relative to 0.9.0. The candidate was published on October 9, 2026 as a prerelease. The candidate version is set in frontend/package.json and its validation branch is release/1.0.0-rc.1. The locally validated code commit is 75c39f186d8f9cff4afa2194753ffbc881f72656, including the Go 1.27.2 security update. Remote CI is deferred by the owner because GitHub billing prevented every check job from starting. The registry image digest is recorded in 1.0.0-rc.1-image.json.

## Security and integrity

- Terminal sessions stop when access is revoked or expires, including cancellation during SSH session opening.
- Private caches, tabs, requests and streams belong to a session generation and are cleared when identity changes.
- Remote uploads use staging owned by the transfer. Resume refuses another transfer's staging, and failed replacement preserves the original file.
- Canonical path checks and bounded archive, Office, metadata and tree readers prevent unbounded work and unsafe path reuse.
- Production HTTPS configuration validates the public origin and restricts trusted proxies. Backup and restore preserve the instance encryption key.

## Connections and diagnostics

- SFTP supports the secure key exchanges implemented by the pinned SSH dependency, including enterprise group-exchange SHA-256.
- Secure MAC and server/authentication signature policies are explicit; obsolete algorithms remain disabled.
- SSH negotiation failures report the failed category and server algorithms instead of a generic connection error, without automatic retries.
- SFTP TCP connection timeouts stop automatic attempts and explain that network, server availability or access restrictions need checking.
- A connector's deadline or cancellation no longer restarts a shared connection indefinitely.
- Copies reserve connections in a consistent order. Sites limited to one connection reject unsupported streamed copies before moving bytes.

## Interface and performance

- Deferred editor, terminal and viewers reduce initial JavaScript while keeping import failures recoverable.
- Downloads and site-tree movement use reusable controllers; bounded tree traversal and session coordination are shared across features.
- Previews refresh after file changes; cancellation stops active work, and disconnect behavior is consistent across views.
- Initial JavaScript remains under the 500,000-byte gzip budget.

## Upgrade notes and limits

- Back up PostgreSQL and `/data`, including the instance key, before upgrading. Restore and rollback from 0.9.0 have been exercised locally.
- Legacy `<destination>.part` files are preserved but are not automatically adopted: restart the upload through the documented recovery flow.
- Safe replacement depends on the server's capabilities. FTP servers without a safe replacement operation refuse overwrite while preserving the original.
- This candidate supports one application instance. Locks do not coordinate multiple replicas or other clients writing to the remote server.
- Retention runs by explicit operator action; recoverable transfers and remote staging are not automatically deleted.

## Validated local image

The Linux/amd64 image `transferly:1.0.0-rc.1` reports `v1.0.0-rc.1` from both its binary and authenticated API. The [image metadata](1.0.0-rc.1-image.json) records its OCI index, platform manifest and exported archive checksums. The archive is local at `/tmp/transferly-release/transferly-1.0.0-rc.1.tar`, with `SHA256SUMS` beside it; the same archive is now attached to the published prerelease.

The first build exposed CVE-2026-78667 and CVE-2026-97031 in Go 1.27.1. It was replaced with a build pinned to Go 1.27.2; [official release notes](https://go.dev/doc/devel/release#go1.27.2) describe the security fixes released on October 8. Production and development Dockerfiles and the module minimum now use 1.27.2. The update is local commit `75c39f1`; the GitHub candidate branch still points to the earlier `cfe9a8b` commit.

Validation of the replacement: full Go suite with race detection and 100% function coverage; lint/types via the commit hook; govulncheck finds zero affected symbols or imported packages (six advisories remain in required modules without affected use); Trivy reports zero HIGH/CRITICAL findings even without ignoring unfixed findings; binary/API versions match; archive reload succeeds; 163 browser tests pass without retries, with 19 documentation capture tests deliberately skipped. The frontend code is unchanged from its previous complete 1,296-test/100% gate.

To verify and load the local archive:

```sh
cd /tmp/transferly-release
sha256sum -c SHA256SUMS
docker load -i transferly-1.0.0-rc.1.tar
docker run --rm transferly:1.0.0-rc.1 version
```

The local artifact identifiers above are supplemented by the verified registry reference below. Public repository/package configuration and the final stable release remain pending; main integration and RC publication are complete.
