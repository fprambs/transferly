# Brief: T7 of the terminal client

Status on 2026-11-26: T0–T4 are done on `feat/terminal-client` (sign-in, explorer, server questions, transfers with queue and progress,
folders, `make tui-it`). The owner approved the mockups of T7 (`docs/design/terminal-client-mockups.md`, screens `t7-*.png`, code in
`tui/mockups/src/t7.rs`). Build them in this order, one commit per step, every gate green after each (see `AGENTS.md`). Update the T7
items of `docs/ROADMAP.md` with `[x]` and a short Spanish summary as each lands, and add the real screen to `tui/mockups/src/real.rs`.

## 1. Mouse (default on)

- `config::Settings` gains `mouse: bool` (default `true`); `/config` shows it as "Mouse: yes/no" (this computer).
- `platform.rs`: `EnableMouseCapture` when on (and `DisableMouseCapture` on exit and when turned off at runtime: add
  `Effect::Mouse(bool)` handled in `platform.rs` through a port, like `copy`).
- `ui::from_terminal`: map `MouseEvent` to `Event::Mouse { kind, column, row }` (down left, down right, scroll up/down, double click
  measured in `App` with the clock of `Event::Tick` or an `Instant` carried by the event).
- Hit testing is pure: `render` already computes the layout; store the last areas in `Home` (`Cell<…>` or a `Layout` computed by a pure
  fn from the frame size, called by both `render` and the mouse handler — prefer the pure fn).
- Click: focus a panel and select the row under the pointer; double click: open (folder, site, or the Enter action on a file); wheel:
  move the cursor of the panel under the pointer; click on list rows of popups, on buttons of confirmations, on chips and keys of the bars.
- Help says "Shift + drag to select text"; the approval link keeps `c` to copy.

## 2. Bars of termscp (`t7::bars`)

- Under each explorer panel one line of chips: `Sort Name ↑`, `Hidden no`, `Filter —` / text, `Sync off` (sync arrives in step 7). A
  click on a chip does what its key does (`s`, `S`, `.`, `f`).
- Bottom row of keys for the focused panel (`F1 Help · Tab Panel · Enter Open · F3 View · F4 Edit · F5 Copy · F6 Rename · F7 Folder · F8
  Delete · F9 Menu · F10 Quit`), keys on the accent, clickable; it drops items from the right on narrow terminals. The status bar keeps
  only the session (server, account, workspace, vault, transfers).
- Add `F6` (rename, same as `F2`) and `F9` (menu, step 3).

## 3. Context menu (`t7::context_menu`)

- Right click on an entry, or `F9`, opens a menu next to it: Open, View, Edit, Copy to the other panel, Rename, Copy the path (OSC 52
  through the existing `copy` port), Details, then Delete in the danger color. Arrows and Enter, or click; Esc closes.

## 4. Sites as a table and the forms of termirs (`t7::site_list`, `t7::new_site`)

- A view of the sites (key `S` on the sites panel, or `/sites`): table with Name (collection / site), Host, Port, User, Kind, Last used;
  search with `/`. `Enter` opens in the focused panel.
- `N` new, `E` edit, `D` delete (confirmation in red naming it), `C` duplicate (API `secretsFrom`), `M` move to a collection.
- The form is drawn from the schema of the connector: `GET /api/v1/connectors` gives fields, kinds, groups, defaults and conditions (see
  `backend/internal/core/connectors` and `frontend/src/features/connectors`, which already does it in the web — mirror its rules).
  Secrets go in `secrets` and need the vault unlocked (reuse the vault popup). `Ctrl+T` tests with `POST …/sites/test` (see
  `SiteDraftTest` in the contract); host keys are trusted with the existing popup.
- Keys: `Tab`/`Shift+Tab` fields, `←`/`→` on choices, `Enter` saves, `Esc` cancels; refusals of the server (`invalid_config` with its
  field) put the error under that field.

## 5. Import `~/.ssh/config` (`t7::import`)

- Parse `Host`, `HostName`, `Port`, `User`, `IdentityFile`, `ProxyJump` (one level → jump fields); skip wildcards and hosts that look
  like Git servers (`github.com`, `gitlab.com`, `bitbucket.org`) or that already exist (same host, port and user). Show the table, mark
  with Space / `a`, `Enter` creates the marked ones as SFTP sites. Pure parser with tests on fixtures.

## 6. Window of transfers (`t7::transfer_window`)

- Title with the totals (`2 of 5 · 41% · 18.4 MiB/s · 0:42 left`); one row per transfer with a thick gauge (`█` against `░`), green when
  done, red with its code when failed; `p` and `x` act on the selected row; `Esc` hides it, `T` shows it again (both exist).

## 7. Previews with F3 (`t7::preview_csv`, `t7::preview_xlsx`, `t7::preview_text`)

- `F3` downloads the first 4 MiB of the file (Range) to memory and shows it full screen: text and code with line numbers, search
  (`/`, `n`), UTF-8 with lossy decoding; CSV and TSV as a table (detect `,` `;` tab), first 5,000 rows; Excel and ODS with the crate
  `calamine` (MIT; check `make tui-deny`), one tab per sheet, values of formulas; JSON pretty printed. Images and PDF: a line offering to
  open the file in the web (`/web` exists) instead of drawing it.
- `F4` edits: download to a temporary file, run `$EDITOR` (suspend the TUI: `ratatui::restore`, run, `ratatui::init` again, all in
  `platform.rs` through a port), upload with `overwrite` if the file changed, and say it if the remote file changed meanwhile (compare
  size and date before uploading).
- Synchronized browsing (`Ctrl+Y`): entering or leaving a folder in one panel does the same in the other when it exists.
